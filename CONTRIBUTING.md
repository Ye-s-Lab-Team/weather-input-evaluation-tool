# Contributing

Current development workflow:

1. Open or reference an issue for substantive changes.
2. Use `dev` as the active development and integration branch.
3. Create short-lived feature branches from `dev` for specific development tasks when appropriate.
4. Add or update tests and documentation together with code changes.
5. Open a pull request to merge feature branches into `dev`.
6. Merge only after automated tests pass and required review is complete.
7. At approved milestones or releases, merge `dev` into `main` through a pull request.
8. Record user-facing or framework-level changes in `CHANGELOG.md`.
9. Tag reviewed releases so results can be reproduced against a known software version.
