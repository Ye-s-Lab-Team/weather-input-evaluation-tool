# Reference Datasets

This directory is reserved for curated, high-quality reference datasets used to support framework development, benchmarking, and validation under Task 1.2.

Candidate reference datasets may include high-quality observational datasets and reanalysis products identified through the project dataset-selection process.

Final dataset selection, preprocessing procedures, metadata requirements, and benchmark use cases will be defined under Task 1.2 and reviewed with the project team and PMS/PES.
